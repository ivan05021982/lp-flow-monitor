What this is not

  • Not a stress predictor or early-warning system. FLAGGED means a large, non-replenished LP outflow was observed in the window. It is not a forecast.
  • No precision, recall or false-positive claim. In the development-set characterisation, catalogued stress windows and quiet control windows flagged at similar rates.
  • No attribution. Large LP outflows happen for many reasons: rebalancing, one large LP leaving, yield migration. The monitor reports the what, not the why.
  • No generalisation beyond the four pools shown.

Data and method

  • Events. Uniswap V3 pool Mint and Burn logs, read from public RPC nodes. On every run the last 14 days are also read from a second, independent node, and a chain is updated only if the two return the same events.
  • USD value. Token amounts times one price per token per UTC day: the mean of the 24 hourly DefiLlama prices of the token on Ethereum mainnet. The CSV below carries, for every day, the token amounts and the two prices used, so each dollar figure can be recomputed.
  • Status. detect_monitoring_v2 v2.0.0 (source hash 035296e21284…), the detector the weekly log has used since June 2026, kept unmodified in the repository. QUIET: no outflow run. RESOLVED: runs occurred, but every assessable run was replenished or did not persist. PENDING: a run is too close to the window's end to assess. FLAGGED: at least one fully assessable run failed replenishment and persisted. detect_monitoring_v3 in the same repository is its fail-closed successor and is not what classifies these windows; the limits of v2 are listed in the README.
  • Change of source. Up to the window ending 2026-09-16 the weekly log was computed from Dune. Dune's free plan stopped running queries in September 2026, so later windows are computed from chain logs. The change was checked against the Dune extractions kept on disk: on every day covered by both (2026-04-21 to 2026-09-16) the number of Mint and Burn events per day is identical, and on each of the 108 historical 45-day windows of these four pools the detector returns the same status and the same outflow runs, with the window net differing by at most 0.03% of the window's gross inflow. All daily figures on this page, including the days before the switch, are computed from chain logs with the price above.
